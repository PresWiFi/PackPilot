## What's new
- **Assign to multiple groups** when uploading to Intune. Search for groups and add them to a selected list; results from different searches are kept. Each group gets its own assignment.
- When updating an existing app, groups it's already assigned to are skipped instead of failing.
- If one group can't be assigned, the others still are, and PackPilot shows which ones failed. The upload record and report show what was actually assigned.
- `Deploy-ToIntune.ps1` takes several groups: `-GroupId <id1>,<id2>`.

## Known limits
- **The Intune upload is still being tested against real tenants.** Try it in a test tenant or assign to a pilot group first, and please [open an issue](https://github.com/PresWiFi/PackPilot/issues) if something goes wrong.
- A group that already has the app assigned is skipped even if you chose a different intent. Change it in the Intune admin center.
